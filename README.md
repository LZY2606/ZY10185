# 流场证言板

本地 TypeScript/Node.js 应用，用于对固定 PIV 流场进行可复核的矢量质量检查、修复和派生场计算。SQLite 保存固定原始数据与每次运行记录，Canvas 同时用于浏览器交互和服务端 PNG 渲染。

## 安装与演示

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm test -- --run && corepack pnpm dev --host 127.0.0.1 --port 5525
```

打开 `http://127.0.0.1:5525`，页面标题为“流场证言板”。

其他命令：

```bash
corepack pnpm typecheck
corepack pnpm db:reset
```

## 固定数据口径

fixture 位于 `src/fixture.ts`，为 6×4 非均匀网格：

- `x = [0, 1, 3, 4, 7, 8]`
- `y = [0, 2, 3, 6]`
- 共 4 个帧对。
- 干净基准场为 `u = 1 + 0.9*y, v = 0`，形成真实剪切层。
- 第 1 帧含边界空洞。
- 第 2 帧含连续三格遮挡 `(1,1)、(2,1)、(3,1)`、边界空洞和孤立错误峰。
- 第 3 帧是完整对照帧。
- 第 4 帧含孤立错误矢量和独立低峰比点。

默认检查可任意组合：

- 中值残差：只统计当前帧 8 邻域中的有限、原始、`valid` 矢量；低于最少邻点数时不出具失败结论。
- 相关峰比：峰比低于阈值判无效；缺失峰比也不通过。
- 速度范围：`sqrt(u²+v²)` 超过阈值判无效；非有限 `u/v` 按缺失传播，不归零。
- 时间一致性：与上一帧同格点的“原始 finite valid 矢量”比较最大分量差，不读取修复场。

默认阈值为中值残差 2.5、峰比 1.5、速率 8、时间分量差 3、最少支持邻点 3。

## 严格分层

每个点都独立保留以下证言：

1. **原始矢量**：`rawU/rawV/peakRatio/sourceStatus`。
2. **检查结果**：`invalid`、失败检查、失败原因、中值残差、时间差、实际进入统计的邻点。
3. **替换值**：`fieldU/fieldV/fieldSource/methodDetail/supportPoints`。
4. **派生场**：只从当前选定场版本计算 `vorticity/divergence`。

修复方式：

- `leave`：无效点留空，不借用任何值。
- `interpolate`：反距离加权局部插值。支持点只来自当前帧当前时刻已经通过检查的原始点；遮挡、缺失、失败点和本次刚生成的替换值都不能作为支持点。
- `previous`：只引用上一帧同格点通过检查的原始值；不引用上一帧插值值，也不继续向前追溯。
- 场版本可选择“仅原始通过点”或“修复后选定场”；涡量和散度始终从当前选择的版本计算。

邻域支持点少于配置值时保留空洞。遮挡点不进入任何邻域统计。边界只取实际存在的相邻网格，绝不通过环绕索引借用另一边数据。

## 非均匀导数

内部点使用实际坐标中心差分：

```text
vorticity  = dv/dx - du/dy
divergence = du/dx + dv/dy
dx = x[i+1] - x[i-1]
dy = y[j+1] - y[j-1]
```

边界点不给单侧导数。中心或任一邻点在选定场版本中缺失时，涡量和散度均为缺失，不以零替代。完整对照帧的手算结果是：剪切斜率 `du/dy = 0.9`，所以 `vorticity = -0.9`；`u` 不随 x、`v=0`，所以 `divergence = 0`。

## SQLite 与重放

数据库默认位于 `data/flow-board.sqlite`，可用 `FLOW_DB_PATH` 覆盖。表结构：

- `datasets`：固定数据集及坐标。
- `frames`：帧对元数据。
- `raw_vectors`：原始 PIV 矢量、峰比和遮挡/缺失状态。
- `run_records`：每次分析的配置与汇总。
- `run_points`：每个点的完整分层证言 JSON。

页面点击“清空并重新导入 fixture”会删除旧数据和运行记录后重新导入；也可运行 `corepack pnpm db:reset`。每次分析后可通过“导出本次运行”下载 JSON，用于离线复核。清空数据库、重新导入、使用相同配置重跑即可复现实验。

## 自动化测试

`tests/analysis.test.ts` 覆盖验收口径：

- 真实剪切层不被阈值误伤。
- 孤立错误、低峰比、时间不一致能分别给出原因。
- 遮挡点和边界空洞不进入邻域。
- 三种修复方式的来源、支持点和空洞行为。
- 插值不连锁借用刚生成值。
- 非均匀坐标中心差分与手算一致。
- 浮点非数值按缺失传播。

`tests/db.test.ts` 验证清空后重导入和运行记录导出；`tests/server.test.ts` 验证 HTTP 页面、API、重导入和服务端 Canvas PNG。
